# 🔍 Resistor Scanner

An AI-powered web app that detects resistor color bands from an image and predicts the **resistance value and tolerance**.

## 🌐 Live Demo

👉 **[Try Resistor Scanner](https://resistor-scanner.vercel.app/)**
